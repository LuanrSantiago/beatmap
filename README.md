# beatmap
Radar de eventos de música eletrônica

Projeto com o intuito de aprender como criar um aplicativo do zero, desde a criação do backend, frontend, machine learning, web screaping, revisionamento e banco de dados.

Atualmente será dividido em 

Roadmap — ~5 a 7 meses (4h/semana)

Fase 0 — Fundação & Git - CONCLUIDO
1–2 semanas
Python virtual env · Git · GitHub · estrutura de pastas · VS Code

Fase 1 — Banco de dados - CONCLUIDO
2–3 semanas
PostgreSQL · schema design · migrations · SQLAlchemy ORM · Supabase

Fase 2 — API backend - CONCLUIDO
3–4 semanas
FastAPI · endpoints REST · Pydantic · autenticação JWT · testes com Pytest

Fase 3 — Scraping engine
4–6 semanas
BeautifulSoup · Playwright · cron jobs · tratamento de erros · normalização

Fase 4 — Frontend React
6–8 semanas
React · Tailwind CSS · consumo de API · componentes · roteamento

Fase 5 — Auth, features & deploy
3–4 semanas
Login · status por usuário (vou/pensando/comprei) · CI/CD · Vercel + Render
